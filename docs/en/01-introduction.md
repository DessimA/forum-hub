# 01 - Introduction to FórumHub

## 💡 Overview
FórumHub was conceived as an engineering challenge to create a complete, secure, and scalable discussion platform. Unlike traditional forums, this project prioritizes **code quality** and **action traceability**.

## 🎯 Project Goals
- **Security:** JWT implementation and profile-based access control (ADMIN, MODERATOR, USER).
- **Compliance:** Mandatory Audit system for all administrative actions.
- **Engineering:** Over 80% test coverage and strict application of Design Patterns.

## 🛠️ Key Features
- **Topic Management:** Creation, editing, deletion, and filtered search.
- **Answers and Solutions:** Users can reply to topics, and the author can mark a reply as a solution.
- **Advanced Moderation:** Temporary or permanent user blocking with mandatory justification.
- **Audit:** Immutable record of who deleted what and why.
