# forum-hub

Plataforma full-stack de forum para troca de construcao com arquitetura de monolito modular. Backend em Java 17 com Spring Boot 3.4.1 incluindo sistema de auditoria avancada com snapshots de dados excluidos, cache Redis L2 e UUIDs binarios. Frontend em Vue.js 3.5 com design Deep Dark e Vuetify 3. Containerizado com Docker Compose.

**Stack:** Java 17, Spring Boot 3.4, Vue.js 3.5, Redis, Docker Compose
